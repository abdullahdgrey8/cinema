# Windows Cinema Scene Preview

Offer an opt-in native desktop entry with the verified scene scheduler. The existing Cinema shortcut and qBittorrent library stay on their own profile and port. The new entry uses its own downloads, search history, player history, storage and Windows window. No download or qBittorrent state is migrated.

1. A managed root is a direct `SceneCompanion` or `SceneCompanion-qa-*` child of `%USERPROFILE%\CinemaData`. This per-user folder is outside packaged AppData redirection and is accessible when the shortcut is opened from Explorer. Provision only an absent root through a private sibling stage and an atomic publish. The protected ACL grants access only to the current Windows user and SYSTEM. Verify the pinned payload manifest before copying any of the 27 runtime files. The local schema-1 manifest binds the owner SID, two non-stock ports and SHA-256 of the self-signed IPv4 loopback certificate. A random qB password and independent random scene key stay in the private root. Cinema reads the manifest directly. Only the exact qB child gets the scene key in its dedicated environment because the reviewed native binary's scheduler requires it. Secrets stay out of process arguments, ambient launcher environment, HTTP responses and logs. Failed provisioning cleans only the still-owned stage. A previously published root is never overwritten or automatically removed.
2. The native desktop entry opens `127.0.0.1:3212`, with separate Windows activation and WebView storage. The launcher rejects reparse points in the managed roots and critical paths, verifies the reviewed executable's SHA-256 and the pinned certificate, and proves both the qB Web API login and scheduler capability. It verifies exact Web UI address, port, HTTPS, save path and enabled incomplete path. Those settings remain verified as live values because the downloader rewrites its INI. A TCP listener alone never identifies an owner. Only a verified TLS peer with a positive scheduler capability counts. A running Cinema backend must prove the same profile, certificate, owner and origin through a fresh 32-byte nonce and HMAC before reuse. The native app serializes managed startup across roots. An unknown Cinema or qB listener fails visibly. If qB is absent, start only the pinned executable with its separate `--profile` and ports. After startup repeat the relevant identity proofs before opening WebView. Cancel only an owned child that failed before readiness. A healthy qB remains alive if a later Cinema launch fails. Stock entry startup retains its existing path.
3. The managed app fixes its connection and provides a visible Add magnet action. Accept one link up to 8,192 characters, with a valid v1 or v2 infohash or one of each. Bound the body and submission rate and require Cinema's existing host, origin and session token checks. Force the managed save path and turn off automatic torrent management at submission. Refuse client path overrides and report an exact duplicate without re-adding it. Show a retry message if the engine is unavailable. The empty library explains that existing search plugins and downloads are in the original Cinema shortcut. Scene fetching is for supported incomplete MP4 with a verified playback reserve. The companion downloads other supported sources through ordinary Cinema playback.
4. Verify manifest, certificate and foreign-listener refusal, partial startup, repeat and conflicting launch, secret handling, and invalid, duplicate or disconnected magnet requests. Use synthetic media on a `SceneCompanion-qa-*` root with peer traffic restricted to loopback. Prove the real native launcher and a valid download in the correct companion folder. Check stock before and after using the existing local app's read-only health/library identity and Windows stock process ID, without opening stock settings or download files. The production profile has normal peer networking, separate Web UI and peer ports, and no imported downloads or plugins. Create the optional shortcut only after verification, without overwriting an existing shortcut and without putting secrets in its arguments.

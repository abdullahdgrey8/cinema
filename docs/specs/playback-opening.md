If autoplay is refused, expose manual Play without a hidden or inert control. Respect watched-scene and replacement landing boundaries and preserve focus when dismissing an opener control.
2. Label exact work as finding the video, waiting for the opening or format index, checking format, preparing the opening, or starting the picture. Use calm transitions and a stable layout. Announce meaningful state changes through the existing live status. Keep backend progress and diagnostics separate from the picture handoff. ## Verification boundaries

Only a private internal URL associated with the current converter run may supply the missing-piece witness. A probe, external player, or retiring converter may still own a stream while a new run starts. Bind the observation to the exact reader and wait object and confirm them with the same current child and run after a single 150 ms timer. Clear the timer on changed evidence, stop, ready or exit. A missing manifest confirmed by ENOENT can mean zero segments. A permission or I/O failure is uncertain. Keep the 3.5-second recovery independent of the early path.

The isolated one-segment file exposed a stale FFmpeg progress sample while its private reader waited at a missing piece. Use a 100 ms reporting interval only for incomplete copy runs. Reports can qualify the earlier restart. Published segments still govern playback and seeking.

One UI function owns cover dismissal and validates the attachment generation and URL. Accept a frame near the intended starting position, including a small HLS opening offset. Keep a protected rescue or watched landing hidden until its existing authorization. When frame callbacks are unavailable use decoded data. If playback advances near the intended position with a real decoded surface and the first-frame callback has failed to arrive, let actual media progress release the cover. Manual Play after autoplay refusal is on the cover itself. Saved-position choices and existing recovery remain actionable above or outside it. Moving focus is limited to a focused control being removed. The fade is CSS-owned so stop or a new title cannot inherit an old JavaScript timer.

Use nine cold pairs with alternating baseline/candidate order for each primary profile. Keep the binary versions, verified prefixes and observation window the same across each pair. Count a verified baseline one-segment wait with no frame by 22 seconds as a bounded failure. Use 22 seconds only as a conservative lower bound in comparisons and report how many runs were bounded. Count stalls of at least 350 ms after actual playing and the first frame during the next 2.2 media seconds. Also exercise medium-keyframe and progressing-piece controls and the case where a current manifest appears during confirmation. Keep raw per-run times, qBittorrent request counts by endpoint, visible frame and early-stall observations. Compare medians and require no added mutation endpoints. Check that an unreadable manifest, stale reader or advancing published playlist cannot supply early evidence.

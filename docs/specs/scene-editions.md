# Portable Scene Cards and Edition Atlas

Cinema can relocate one moment and compare two releases using the viewer's own subtitle tracks. This round delivers roadmap items 04 and 03 with the native Scenes panel.

## Acceptance

1. An existing portable scene pin can export a versioned scene-card JSON file through the local download mechanism. The card contains only exact story identity and bounded matching fingerprints. An import on a verified matching movie or episode creates a local pin without source file identity or an absolute timestamp. It is deduplicated, remains saved across reload, can resolve against a differently timed or reflowed subtitle track and never moves playback until an explicit verified Jump. Malformed, unsupported, oversized, wrong-title, duplicate and full-store cases have clear feedback.
2. Edition Atlas explicitly captures the current exact file and loaded adjusted track, and compares a second independently verified file of the same story during its normal playback. Detect stale or identical file/track evidence and decline wrong identities or insufficient confidence. Report shared anchor spans, bracketed dialogue found in only one track when supported and uncertain regions. Separate offset shifts and unknown footage from a claimed edit. Both independently known offsets and an insertion are verified in synthetic cuts.
3. Keep both workflows in Scenes, with keyboard focus, named controls, announcements, reduced-motion and spoiler-safe defaults. Atlas reveals only time and evidence categories after explicit comparison, with passage timings collapsed at first and no raw dialogue excerpt. A passage action targets only the current edition through the existing verified-range seek and exact playback/track recheck. No second media or background search begins.
4. Verify two playable Windows editions, export content and real file picker import, a card relocated without an automatic jump, and matching/insertion evidence. Run focused and sequential regression, independently review the exact current source on both axes, install locally and verify the desktop shortcut and connection. Keep a 2.9.0 rollback snapshot.

## Design boundaries

- Cards use a fixed UTF-8 schema and a 4096-byte cap. Only the version, exact movie title/year or verified episode identity, and existing bounded unsigned-word fingerprints with cue-relative displacement are exported. Notes, raw dialogue, local IDs, torrent identity, file names, paths, media URLs and absolute times stay local. Dialogue fingerprints are matching data and carry no anonymity guarantee. Validate imports from bytes before storage and preserve existing local pin shape and save cap.
- Import remains in the active Scenes panel. A matching verified story can import before its subtitle track is loaded. An asynchronous file read binds to that exact active generation and file so a late picker cannot write against a newly opened title. Use the existing native Blob download pattern and a local Windows file picker, with no remote recipient service.
- Atlas movie identity requires exact selected-file title and year plus the same recognized stable movie provider ID. A verified episode uses its exact provider series and episode IDs associated with the selected file. The two file keys must differ. Require both captures to be from active decoded sessions. Snapshot only the adjusted timing and bounded normalized dialogue data needed for a comparison, hold the saved first edition in memory until discarded or app close, and reject duplicate subtitle evidence even when the viewer applied a timing offset.
- Use ordered distinctive text anchors, with duplicates and conflicting order treated conservatively. Keep sparse, conflicting, reflow-uncertain and outside-anchor passages as unknown. A shared interval needs supporting neighboring anchors with coherent relative timing. One-track evidence needs reliable matched boundaries, a material duration difference, and multiple substantive unmatched phrases localized to the longer side. Captions may differ from the picture. Atlas reports dialogue evidence only and never interpolates a seek across gaps.
- Bounded normal use requires no new dependencies, renderer processes, downloading, external requests, backend credentials or destructive operations. Compare on explicit user action, and keep play, subtitle editing, scene finding and existing local pins available independently. Plan review and release checks use an isolated copy.
